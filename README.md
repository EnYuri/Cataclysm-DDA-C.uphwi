# Cataclysm-DDA (Cuphwi Fork)

This repository is a personal, private fork of Cataclysm: Dark Days Ahead for a small hobby community.
It is not affiliated with the upstream project.

## What this fork is for
- Local gameplay tweaks and experiments
- Small quality-of-life changes for our group
- Not intended for upstream contribution

## Notable changes
- sub_comp-based alternative component system (recipe JSON unchanged)
- Brass catcher handled via flags (no hardcoded type checks)
- Crafting UI performance fixes related to requirement expansion/indexing

## Build
This fork is built the same way as upstream (Windows/MSYS2/CMake, etc.), unless noted otherwise.
See:
- COMPILING.md
- doc/ (build notes and tooling)

## Downloads
No public releases. Builds are shared within the private community only.

## Support / Bug reports
Do not report issues to upstream.
If something breaks, report it to the maintainer of this fork (this repo).
