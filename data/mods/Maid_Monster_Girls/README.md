# Maid Mods + Monster Girls Compatibility

Enable **Maid Mods + Monster Girls Compatibility** with Battle Maid Redux,
KawaiiMaidMod, and Monster Girls Mutations. Its dependencies load the three mods
in the required order.

Monster Girls changes several vanilla mutation categories and thresholds. This
patch adds the corresponding Monster Girls categories and thresholds to
mutations used by the maid mods while retaining their maid categories. It does
not replace the source mods or alter existing characters' mutations.
